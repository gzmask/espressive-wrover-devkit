## 手动恢复（尚未由操作者实测）

1. 保持 USB 供电，关闭占用 UART 的串口监视器。
2. 按住 **BOOT（GPIO0）**，按下并松开 **EN**，再松开 BOOT。
3. 重新确认端口后，用只读命令验证 ROM 通信：

```sh
# 先激活BUILD.md中的固定IDF环境；PORT必须填重新发现的B/UART。
python -m esptool --chip esp32 --port "$PORT" --baud 115200 \
  --before no_reset --after no_reset --no-stub --connect-attempts 1 chip_id
```

示例明确保持ROM状态，不主动退出下载模式；需恢复应用时，松开BOOT后正常按EN。打开串口的OS/驱动可能造成控制线瞬态，不能仅因脚本未主动复位就声称设备从未复位。
