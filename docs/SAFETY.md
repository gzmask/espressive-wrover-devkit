# 设备操作与公开发布边界

## 当前设备

开发板为 ESP-WROVER-KIT v4.1 / 经典 ESP32。开发设备已通过真实 HTTPS OTA 更新到 `0.1.7-ota-wifi`，运行 B 槽 `0x160000`，启动状态 VALID；验收结果见 [测试结果](TEST_RESULTS.md)。源码默认版本和配置不等于当前上板配置。

- 此前的应用、引导、分区表及 OTA 控制区写入授权已全部消耗。新构建、提交代码或发布仓库都不是再次写入设备的许可。
- 每次新刷写须重新批准准确镜像 SHA-256、目标槽、写入/擦除范围和尝试次数；失败后不自动重试、重刷或恢复备份。
- 不执行通用 `idf.py flash`、`@flash_args`、整片擦除、eFuse 修改、安全启动/Flash 加密或 anti-rollback 配置变更。
- OTA 只写非运行应用槽，不提供网络更新 bootloader/分区表的接口。后续 OTA 固件必须保留相应健康确认及回退配置；默认关闭配置不能随意上传。
- 保留原 NVS、free、旧用户数据及所有授权范围外 Flash。备份、恢复和分区迁移均需单独规划和批准。
- 不自动重启设备或路由器、干扰网络、改跳线/供电、拆屏或拆焊器件；官方资料中的改板选项不是操作授权。

本机详细交接与私有证据索引在被 Git 忽略的 `AGENTS.md` 和 `.local/` 中，不随公开仓库发布。公开说明不能替代实际设备的身份、状态和写入前核对。

## 凭据、产物与网络

- Wi-Fi 凭据、OTA token、TLS 私钥由项目外或私有目录的文件在构建时嵌入，不把值写进源码、sdkconfig 或命令行。私有目录 0700，输入/日志 0600，冻结产物 0400。
- 含上述秘密的 BIN/ELF/生成汇编/目标文件和 Flash 快照只能私有保存；不提交、推送、上传 Release 或分享。关闭 ccache，不自动重新生成正在使用的 key/token。
- 原始 Flash、设备 IP/MAC、串口采集、用户照片和主机专用交接均不发布。测试里的假凭据和模拟地址不是实机秘密。
- HTTPS 客户端校验固定服务端证书及主机名，不使用 `-k`。GET `/health`、`/status` 不要求 Bearer；POST `/ota` 必须独立 Bearer 认证。HTTP 200 不代表 healthy。
- 该服务仅供可信局域网使用，不暴露公网；上传认证不是固件签名、secure boot 或任意断电安全保证。

## 发布前检查

1. 只暂存源码、测试、构建默认配置与公开文档；审查实际 Git index，而非只相信忽略规则。
2. 排除 `.local/`、构建目录、生成 sdkconfig、凭据、key、固件产物、日志及私有交接。
3. 核对制造商资料和第三方代码的许可；[官方参考资料](references/espressif/README.md) 的原始 HTML/图片/PDF/DXF 仅在本地保存，公开仓库提供来源及校验值。
4. 运行主机测试、适用的 lint/格式检查，检查文档链接；mock 与主机测试不代替实机证据。
5. 不选择、改变项目开源许可证或强推历史，除非另行明确要求。

精确构建见 [构建说明](BUILD.md)，设备更新与恢复边界见 [OTA](OTA.md) 和 [烧录与恢复](FLASH_AND_RECOVERY.md)。
